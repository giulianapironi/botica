# Botica

Landing de una cafetería de especialidad ficticia, instalada en una antigua botica de San Telmo, Buenos Aires. Proyecto conceptual hecho con HTML, CSS y JavaScript, sin dependencias.

## Qué incluye

- Hero y sección "La casa".
- Recetario con pestañas (Café, Fríos, Pastelería), generado desde JavaScript.
- Galería de fotos.
- Formulario de reserva de mesa con validación (la reserva no se guarda en ningún servidor).
- Modo claro y oscuro según la preferencia del sistema, y diseño adaptado a móvil.

## Estructura

```
index.html      Estructura de la página
css/estilos.css Estilos
js/main.js      Menú, pestañas y formulario de reserva
img/            Fotografías
```

## Cómo verlo

Abrí `index.html` en el navegador. Las tipografías (Young Serif y Work Sans) se cargan desde Google Fonts, así que hace falta conexión para verlas.
